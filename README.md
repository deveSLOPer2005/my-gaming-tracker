# my gaming tracker

Простой веб-трекер для отслеживания статуса прохождения компьютерных игр. Проект написан на чистом PHP с разделением логики по принципу MVC (Model-View-Controller) и полностью контейнеризирован с помощью Docker.

## Технологический стек
* **Язык:** PHP 8.2
* **Веб-сервер:** Nginx
* **База данных:** MS SQL Server (PDO, с защитой от SQL-инъекций)
* **Окружение:** Docker + Docker Compose

## Функционал
* Полный CRUD для управления списком игр (добавление, просмотр, редактирование, удаление).
* Фильтрация игр по статусу прохождения.
* Постраничная пагинация списка игр.
* Система авторизации пользователей и регистрация новых аккаунтов с хэшированием паролей.
* Безопасное удаление профиля пользователя со всеми связанными данными из БД.

## Локальный запуск через Docker

Требуется установленный Docker Desktop.

1. Клонируйте репозиторий и перейдите в папку проекта:
   ```bash
   git clone https://github.com
   cd my-gaming-tracker
   ```

2. Скопируйте файл `.env.example` и переименуйте его в `.env`.
   Откройте `.env` и впишите туда свой логин и пароль от MS SQL Server.
   Сохраните изменения в файле.

3. Запустите контейнеры командой:
   ```bash
   docker compose up -d
   ```
4. Откройте браузер и перейдите по ссылке: `http://localhost`.

Для остановки проекта используйте команду:
```bash
docker compose down
```

**Примечание по БД:** Для подключения контейнера к локальной базе данных Windows в `db.php` настроен сетевой мост через `host.docker.internal` со строкой DSN, отключающей принудительное SSL-шифрование.
